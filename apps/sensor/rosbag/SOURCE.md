# Rosbag writer source

`rosbag_v2_writer.cpp` and `rosbag_v2_writer.h` are derived from the public
Hessian-matrix/RoboBaton_4p_demo repository and remain under Apache License
2.0. They implement only the ROSBAG V2.0 container writer. The ORBVI camera,
IMU, encoder, RTSP and BSP integration do not use that repository's prebuilt
libraries.
